The footer voluntarily credits the contributors. No reference-site asset is shipped. The authored ambient/click/hover/toggle WAVs remain the audio defaults and fallback; no licensed replacement audio was selected.

Other tracked public files, preserved from the existing repository: `audio/{ambient,click,hover,toggle}.wav` (authored synthesized audio); `seo/og.png` and `seo/social-card.svg` (authored portfolio branding); `images/.gitkeep`, `seo/.gitkeep`, `uploads/.gitkeep`, `videos/.gitkeep` (empty directory markers). Thus `git ls-files public` contains this inventory, rather than deleting the site's existing own assets.

Reference-only files may be placed in ignored `public/_reference/`. The build and tracked pre-commit hook reject tracked references, byte-identical copies under other names (index and working tree), and source references to that directory. Activate the hook after cloning with `git config core.hooksPath .githooks`. No reference files are currently needed or shipped.

Default/hover pairs preserve each icon geometry and change stroke weight. No new package or downloaded brand mark.
